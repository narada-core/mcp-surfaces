## Workflow

1. Work top-down by package, preserving each package's existing module API.
2. Split at Rust item boundaries; avoid mechanical line slicing through `impl` blocks, attributes, or tests.
3. Run formatting and focused package tests after each package-level batch.
4. Mark an item complete only after the source is split and its relevant checks pass.
5. Re-run the inventory at the end and update LOC counts.
