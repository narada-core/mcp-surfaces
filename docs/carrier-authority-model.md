# Carrier authority model

Narada evaluates carrier authority along independent dimensions. No single
orientation result is a global permission switch.

| Dimension | Canonical evidence | Effect when absent |
| --- | --- | --- |
| Carrier materialization | generation sidecar and binding-admission envelope | materialized surfaces unavailable |
| Session attestation | launcher admission and orientation receipts | named identity unavailable |
| Agent identity | exact session receipt | identity-bearing operations refused |
| Site authority | materialized binding inventory and allowed Site roots | that Site cannot be activated |
| Binding activation | Loader connection state | that surface cannot be called yet |
| Lifecycle participation | materialized task-lifecycle scope | turn poll is `not_applicable` |

Ambient carriers are intentionally anonymous. They retain host and User-Site
authority admitted by materialization and may activate admitted bindings. A
surface still enforces its own Site, identity, effect, and mutation contract.
Site access never establishes identity, and identity never admits a Site.

## Orientation and inbox

`agent_orientation_read` supplies named-session context. If exact entry evidence
is absent, it returns `narada.agent_context.orientation_unavailable.v2` with an
open ordinary-work gate and an explicit statement that materialized authority is
unaffected. Starting an admitted session is recovery only for identity-bearing
work.

Opening and closing lifecycle polls are separate from orientation. An anonymous
carrier polls the carrier/User-Site inbox when that surface is materialized but
must not claim, acknowledge, or reply as a named recipient. Applicability comes
from trusted materialized state, never from an agent assertion.

## Binding recovery

Loader refusals identify the blocked operation, failed authority dimension,
unaffected authority, repair owner, agent repair permission, and restart need.
An absent binding is a Site configuration or materialization concern; an agent
must not manufacture admission merely because a tool would be useful.

## Pi projection

Pi eagerly exposes only agent context, User-Site filesystem, Loader, and task
lifecycle. All remaining admitted Site capabilities stay available through the
Loader inventory and are opened lazily. This makes authority available without
placing every Site tool schema permanently in model context.
